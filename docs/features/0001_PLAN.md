### Manage Systems in an Organisation — Technical Plan

Brief: Add a first-class feature to catalog and manage organisational systems (applications/services) with ownership, lifecycle status, criticality, dependencies, and basic reporting. Follow existing feature patterns (e.g., Products, Contacts) using Clean Architecture, CQRS/MediatR, and Blazor Server UI.

Feature name and entity naming: Use `OrgSystem` (not `System`) to avoid collision with the `System` namespace.

Scope (from user request): “manage the systems in an organisation.” Includes: create/edit/delete, list with server-side filtering/pagination, export, basic import (optional), permissions, and navigation.

Files to add or modify

- Domain
  - Add `src/Domain/Entities/OrgSystem.cs` with key fields: Name, Description, BusinessOwnerId (Contact ref), TechnicalOwnerId (Contact ref), Criticality (enum), LifecycleStatus (enum), Tags/Capabilities (string list), Created/Updated audit via `BaseAuditableEntity`.
  - Add enums in `src/Domain/Enums/` if not present: `SystemCriticality`, `SystemLifecycleStatus`.
  - Consider simple dependency representation for v1 (comma-separated `Dependencies`), deferring relational graph to later iteration.

- Infrastructure (EF Core)
  - Update `src/Infrastructure/Persistence/ApplicationDbContext.cs`: add `DbSet<OrgSystem> OrgSystems`.
  - Add configuration `src/Infrastructure/Persistence/Configurations/OrgSystemConfiguration.cs` (required properties, max lengths, indexes on Name, Criticality, LifecycleStatus).
  - Generate migrations across providers in `src/Migrators.*` projects to create the `OrgSystems` table and indexes.

- Application (CQRS/MediatR, DTOs, Caching, Specs, Permissions)
  - Create feature folder `src/Application/Features/OrgSystems/` mirroring `Products` structure:
    - Caching: `OrgSystemCacheKey.cs` (keys + tags pattern like `ProductCacheKey`).
    - DTOs: `OrgSystemDto.cs` with AutoMapper mapping to `OrgSystem`.
    - Commands:
      - AddEdit: `AddEditOrgSystemCommand.cs` (+ validator) — follow `AddEditProductCommand` in `src/Application/Features/Products/Commands/AddEdit/AddEditProductCommand.cs` for handler structure using `IApplicationDbContextFactory` and `IMapper`.

      - Import (optional v1): `ImportOrgSystemsCommand.cs` — wire later if needed.
    - Queries:
      - Pagination: `OrgSystemsWithPaginationQuery.cs` — server-side filtering and sorting, shaped like `ProductsWithPaginationQuery`, using keyword, Criticality, LifecycleStatus, OwnerId filters; ProjectTo DTO and return `PaginatedData<OrgSystemDto>`.
      - GetAll / GetById as needed for UI dialogs.
      - Export: `ExportOrgSystemsQuery.cs` — to Excel/PDF, aligned to `ExportProductsQuery`.
    - Specifications:
      - `OrgSystemAdvancedFilter.cs`, `OrgSystemAdvancedSpecification.cs` for keyword and field filtering consistent with other features.
    - Security/Permissions:
      - `src/Application/Features/OrgSystems/Security/OrgSystemsPermissions.cs` exposing constants `Permissions.Systems.View`, `.Create`, `.Edit`, `.Delete`, `.Export`, `.Import`.
  - Resources (localization): add resx entries under `src/Application/Resources/Features/OrgSystems/` for DTO/member descriptions.

  - Resources: add page string resources under `src/Server.UI/Resources/Pages/OrgSystems/`.

Algorithms and processing steps

- Add/Edit flow (server side):
  1) Map command to entity via AutoMapper.
  2) Use `IApplicationDbContextFactory.CreateAsync(ct)` to get context.
  3) If `Id > 0`, fetch `OrgSystem` by Id; if not found, return `Result.Failure`.
  4) Update fields; SaveChanges; return `Result<int>.Success(entity.Id)`.
  5) On create, add entity, SaveChanges, return new Id.
  6) Invalidate caches via `ICacheInvalidatorRequest` Tags from `OrgSystemCacheKey`.

- Pagination query (server side):
  1) Receive `PageNumber`, `PageSize`, `OrderBy`, `SortDirection`, `Keyword`, `Criticality`, `LifecycleStatus`, `OwnerId`.
  2) Build `IQueryable<OrgSystem>` with specification filtering (keyword on Name/Description/Tags/Dependencies; exact filters on enums and owners).
  3) Apply ordering and `Skip/Take`.
  4) `ProjectTo<OrgSystemDto>(mapper)`; materialize items; compute `TotalItems` for `PaginatedData`.

- Export query:
  1) Reuse filters from pagination.
  2) Materialize DTOs, shape to export rows; call existing Excel/PDF service to generate file bytes.

- UI grid behavior:
  1) On grid state change, set `OrderBy`, `SortDirection`, `PageNumber`, `PageSize` and invoke Mediator with `OrgSystemsWithPaginationQuery`.
  2) Toolbar: Create opens `OrgSystemFormDialog` with empty model; Edit maps selected DTO to command; Delete uses bulk command; Export triggers export query and downloads bytes.
  3) Respect access rights via `PermissionService.GetAccessRightsAsync<OrgSystemsAccessRights>()`.
